
# Sistema de Aluguel de Carros 🚗

## 📌 Sobre o projeto

Projeto acadêmico de banco de dados desenvolvido com SQL e MySQL para organizar informações de clientes, carros, sedes, classes de veículos e reservas de aluguel.

## 🛠️ Tecnologias utilizadas

- MySQL
- SQL
- MySQL Workbench

## 🗄️ Estrutura do banco

O banco `db_formula_de_um` possui cinco tabelas:

- `classesCarro`: classes e valores das diárias.
- `sedes`: informações das unidades.
- `clientes`: dados dos clientes.
- `carros`: informações dos veículos.
- `reservas`: registros das locações.

Foram utilizadas chaves primárias e estrangeiras para relacionar as tabelas.

## ▶️ Como executar

1. Instale o MySQL e abra o MySQL Workbench.
2. Abra o arquivo `db_formula_de_um.sql`.
3. Execute o script.
4. Confira as tabelas criadas no banco de dados.
